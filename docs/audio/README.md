# Desire Spin audio v3

## Release scope

All existing SFX families and the old oscillator music are replaced by original, offline-rendered stereo samples. Nine instrument palettes cover Olympus (warm bronze/low rumble), Sweet Bonanza (marimba), Sugar Rush (soft glass), Wanted (dry plucked strings/wood), Wolf (low wood and spacious reflections), Pharaoh (darker strings/temple reflections), Juan (bright strings/major-key fanfare), Bass (gentle acoustic/wood), and Originals/lounge (restrained mallets/taps). New cascade-clear, cascade-fall and cascade-land cues follow the actual animation timeline.

There are **189 SFX/music assets plus two Olympus voice excerpts**. The deprecated low-pitched browser speech implementation is completely removed. Olympus was the site's only old speechSynthesis voice. Dealer narration is separate work using the shared voice bus.

The initial Kokoro `bm_george` voice was rejected as too low-energy. The expression-controlled Chatterbox comparison was selected in listening review, so the final Olympus voice uses only that exact selected performance. It is two natural-boundary excerpts, used sparingly:

- Bonus entry: “Behold my power!”
- Major win: “Rise, and claim your glory!”

Ordinary multipliers/lightning no longer trigger extra narration. Captions match the spoken excerpts exactly. No rejected Kokoro line, duplicate eight-file bank or browser-TTS fallback is shipped.

## Voice provenance, rights and watermark

The full original selected WAV is retained in `sources/olympus-selected-original.wav`; its SHA-256, original prompt, generation settings, cue boundaries and output hashes are in `public/audio/v3/voices/manifest.json`.

- Source: [official ResembleAI/Chatterbox public demo](https://huggingface.co/spaces/ResembleAI/Chatterbox), generated 2026-10-08 through its documented API.
- Exact original prompt: `Behold my power! Rise, and claim your glory!`
- Settings: exaggeration 1.25, temperature 0.8, seed 4271, CFG/pace 0.3; no reference audio was submitted for the selected sample.
- The [official model card](https://huggingface.co/ResembleAI/chatterbox) and [code license](https://github.com/resemble-ai/chatterbox/blob/master/LICENSE) declare MIT. A copy of the notice is in `licenses/Chatterbox-MIT.txt`.
- Upstream says generated audio contains its PerTh watermark and that it is designed to survive MP3 compression/editing. No watermark-removal operation was attempted. Detection on the final short excerpts has not been independently tested.
- Processing: split at 1.78 seconds, the middle of a measured 280ms phrase pause (1.636–1.917s), gentle 70Hz high-pass and level matching to -18 LUFS / -3dBTP. No pitch shift or artificial playback-rate effect.
- The demo reuses model conditioning state; consequently “no reference submitted” is not proof of a freshly reset built-in speaker. This is why the release uses only the exact selected synthetic performance, rather than claiming later generated lines have a verified identical actor.
- Further generation attempts returned an opaque upstream error. Two other generated clips and all rejected Kokoro variants are excluded from the final bank. This is a deliberate small-bank fallback with exact captions, not a claim that eight new performances were generated.
- No provider recording was copied, no named real performer was requested, and no personal recording, credentials, payment or account was used. This voice was generated by a public service, **not entirely offline**. The service is absent from website runtime: players download only the committed audio assets.
- MIT/model licensing does not by itself guarantee copyrightability or every third-party right in a synthetic output. The origin and synthetic nature are disclosed rather than presenting it as a human performance.

Kokoro/ONNX were used only for rejected prototype comparisons in this audio task. Their Apache-2.0/MIT notices remain for provenance. No model weights or Python inference runtime are distributed in the site. Any independent dealer bank must document its own provenance.

## Original SFX and music

All motifs, instruments, modal resonances, envelopes, percussion and stereo reflections in `scripts/render-audio.py` were authored for this project, with no downloaded commercial sound packs, copied provider recordings, or released-song samples. Deterministic sample hashes and raw peak values are recorded in `public/audio/v3/manifest.json`.

```sh
python3 scripts/render-audio.py             # NumPy and FFmpeg; all effects/music
python3 scripts/render-audio.py --music-only
python3 scripts/render-olympus-voice.py     # FFmpeg only; exact committed WAV split
```

The final voice reproduction script requires no model inference, network request or telemetry. It cannot silently revert to the rejected vocal direction.

## Controls and lifecycle

The shared engine owns one AudioContext with master/effects/music/voice buses, a compressor, bounded six-source SFX overlap, duplicate debounce, single-instance narration and music ducking. Audio unlock uses a pointer/key gesture, Safari's prefixed context fallback, and a silent buffer primer. There is no fake spoken primer.

Settings and the in-game mixer expose independent global levels/toggles. The game menu additionally offers a saved per-route effects/music/voice mix and mutes. Game levels scale global channels, so no game setting can bypass a global mute. Valid old `sound-on` and `music-on` choices migrate without unmuting anyone. Both schemas reject malformed values.

Leaving a game, hiding the document, pagehide, mute or disposal stops active nodes and invalidates pending playback generations. Stale route callbacks, delayed decodes and old same-track music requests cannot restart canceled audio. Volume changes preserve voice ducking. Assets are fetched from the same origin, loaded by current theme and capped at 48 decoded cache entries. Audio failures never affect game settlement.

Dealer API: `gameAudio.speak(file, expectedRoute, priority, gain, {onStart,onEnd,onError})` returns whether a clip began; `onEnd` reports `ended` or `cancelled`. `stopBus('voice')` invalidates both pending and active speech. File paths are limited to `/audio/v3/`. Natural delivery speed should be generated offline rather than pitch-shifting playback.

## Verification and limits

Focused tests cover lifecycle cancellation, pending requests, overlap, volume, preferences, per-game isolation, accessible controls, route palettes and absence of browser speech. FFmpeg verifies actual asset decoding, hashes and digital levels; `LEVEL_CHECK.json` records final MP3 measurements. Application-wide/browser checks are handled in release integration.

This environment has no audio-perception/listening tool. No human-style listening pass is claimed. The user listened to and selected the source performance. Numerical/automated checks do not establish subjective naturalness or phone-speaker quality; real device/headphone review remains valuable, particularly iOS Safari.
